Excel File Requirements
To import cadets accurately into the database, ensure your Excel spreadsheet (.xlsx / .xls) has the following 3 column headers in the first row (Row 1):
Team Name Batch
1 DELA CRUZ, JUAN A. 2023
2 SANTOS, MARIA B. 2024
3 REYES, CARLOS C. 2025
Key Formatting Guidelines: • Team: Numeric team number (e.g. 1, 2, 3).
• Name: Full name formatted as SURNAME, FIRSTNAME M.I.
• Batch: 4-digit graduation / batch year (e.g. 2023, 2024, 2025, 2026).
• Safety: Existing cadet names in the database are safely skipped to avoid duplicates.
